# PP-INA228-USB Device Plugin

Этот плагин интегрирует кастомный аппаратный модуль INA2282USB в экосистему **Joulescope UI**. Он позволяет управлять устройством через виртуальный COM-порт (USB CDC-ACM), визуализировать данные в реальном времени и записывать их в нативный формат Joulescope (`.jls`) для последующего профессионального анализа.

## 🚀 Возможности

* **Двухканальная визуализация:** Отображение напряжения и тока на двух синхронизированных графиках с независимым автомасштабированием и SI-префиксами (мВ, мкА, нА и т.д.).
* **Запись в формат JLS v2:** Сохранение данных в родной формат Joulescope с корректными временными метками (time64), что позволяет открывать файлы в основном окне Waveform со всеми инструментами анализа (маркеры, статистика, экспорт).
* **Аппаратная калибровка:** Гибкая настройка множителей (Multiplier) и смещений (Offset) для каналов напряжения и тока прямо из интерфейса.
* **Управление частотой дискретизации:** Выбор интервала опроса АЦП в микросекундах (50, 84, 150, 280, 540, 1052, 2074, 4120 мкс) с автоматическим расчетом частоты (sps).
* **Оптимизация производительности:** Возможность полного отключения отрисовки графиков в реальном времени для минимизации нагрузки на CPU (идеально для слабых ноутбуков), при этом запись в файл продолжается на максимальной скорости.
* **Автоматизация:** Опция автоматического открытия записанного `.jls` файла в основном окне Joulescope UI сразу после остановки записи.

## ⚙️ Требования к аппаратному обеспечению

Плагин ожидает устройство, подключенное через USB CDC-ACM (виртуальный COM-порт), поддерживающее следующий бинарный протокол:
* **Команда Старт:** `5 байт данных` + `ID 0x38` + `Enable=1` + `Каналы (1, 2 или 3)` + `Интервал в мкс (uint16)` + `Shunt=0`.
* **Команда Стоп:** `2 байта данных` + `ID 0x38` + `Enable=0`.
* **Блок данных:** `ID 0x3A`, за которым следуют 20-битные значения АЦП (со сдвигом на 4 бита), упакованные по 3 байта на канал (Little-Endian). Ток передается в дополнительном коде (знаковый), напряжение – беззнаковое.

## 📦 Установка

### Шаг 1: Подготовка окружения
Убедитесь, что у вас установлен **Joulescope UI**. Плагин использует интерпретатор Python.

Откройте командную строку (Terminal / CMD) и установите необходимые библиотеки. 
*Если вы используете стандартный установщик Joulescope для Windows, выполните команды, указав путь к Python:*

```bash
# Для стандартной установки Python:
pip install pyserial pyjls pyqtgraph numpy

# Для встроенного Python Joulescope (замените <ВашеИмя> на ваше имя пользователя):
"C:\Users\<ВашеИмя>\AppData\Local\Programs\joulescope\python.exe" -m pip install pyserial pyjls pyqtgraph numpy
```

### Шаг 2: Размещение файлов плагина
1. Закройте Joulescope UI, если он открыт.
2. Перейдите в директорию плагинов Joulescope:
   * **Windows:** `%LOCALAPPDATA%\joulescope\plugins` (вставьте эту строку в адресную строку Проводника)
   * **macOS:** `~/Library/Application Support/joulescope/plugins`
   * **Linux:** `~/.joulescope/plugins`
3. Создайте новую папку с именем `pp_ina228_usb`.
4. Поместите внутрь этой папки следующие файлы:
   * `__init__.py` (основной код плагина)
   * `README.md` (этот файл)
   * `index.json` (файл метаданных, см. ниже)

### Шаг 3: Очистка кэша
Удалите папку `__pycache__` внутри директории `pp_ina228_usb`, если она существует. Это заставит Python заново скомпилировать код при следующем запуске.

## 🎮 Использование

1. **Запуск:** Откройте Joulescope UI.
2. **Активация:** В верхнем меню выберите **Widgets** → **Plugins**. Найдите в списке **PP-INA228-USB Device** и установите флажок **Active**.
3. **Открытие виджета:** Перейдите в меню **Widgets** и выберите **PP-INA228-USB Device**. Виджет появится на рабочем столе.
4. **Настройка:**
   * Укажите правильный **COM port** (например, `COM3` или `/dev/ttyACM0`).
   * Выберите **Режим каналов** (Только ток, Только напряжение, или оба).
   * Выберите **Интервал (μs)**, соответствующий возможностям вашего АЦП.
   * При необходимости введите калибровочные **Множитель** и **Смещение** (поддерживается экспоненциальная запись, например, `3.05e-8`).
   * Нажмите кнопку **💾 Сохранить настройки в файл**, чтобы они применялись автоматически при следующем запуске.
5. **Оптимизация (для слабых ПК):** Снимите галочку *"Показывать графики в реальном времени"*. Это снизит нагрузку на процессор до минимума, при этом запись в файл будет работать корректно.
6. **Запись:** Нажмите **▶ Старт**. Для остановки нажмите **■ Стоп**.
7. **Анализ:** Если включена опция *"Автооткрытие файла в Waveform"*, записанный `.jls` файл мгновенно откроется в главном окне Joulescope UI для детального изучения.

[joulescope_plugin.gif](https://github.com/pvvx/SimplePowerProfiler/blob/main/docs/joulescope_plugin.gif)

## 🔧 Устранение неполадок

* **Виджет не появляется в меню Plugins:** 
  1. Проверьте наличие и корректность файла `index.json`.
  2. Убедитесь, что папка `__pycache__` удалена.
  3. Откройте лог-файл Joulescope (`%LOCALAPPDATA%\joulescope\logs\joulescope_ui.log`) и поищите строки `ERROR` или `FATAL ERROR`, связанные с `pp_ina228_usb`.
* **Ошибка `ModuleNotFoundError`:** Библиотеки `pyserial`, `pyjls` или `pyqtgraph` не установлены в окружении Python, которое использует Joulescope UI. Повторите Шаг 1, убедившись, что используете правильный исполняемый файл `python.exe`.
* **Высокая загрузка CPU:** Убедитесь, что галочка *"Показывать графики в реальном времени"* снята при высоких частотах дискретизации (например, 20 000 sps) на маломощных процессорах.
